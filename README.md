# 实时练唱音高监测 - 美化 Fork

一个纯前端网页，用浏览器麦克风实时检测唱歌音高，显示音名、频率、与最近标准音的 cents 偏差和稳定性，并用钢琴窗记录最近一段时间的音高轨迹。

## 本地运行

由于浏览器麦克风权限通常要求安全上下文，建议用本地 HTTP 服务打开：

```powershell
python -m http.server 3001
```

然后访问：

```text
http://localhost:3001

## Fork 说明

这个目录是从当前稳定版复制出来的美化分支，可以在这里调整视觉设计、布局、动效和配色，不影响 `voice` 目录里的稳定版。
```

## 使用建议

- 使用 Chrome 或 Edge。
- 先唱稳定长音，减少颤音和滑音。
- 安静环境下检测更准。
- ±10 cents 内通常已经很准，初练可以先追求 ±25 cents 内。

## 说明

检测逻辑运行在浏览器本地，不会上传录音。网页端音高识别会受麦克风、环境噪声、音量和发声方式影响，适合作为练习参考。
