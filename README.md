# Vocal Studio - 实时练唱音高监测

Vocal Studio 是一个纯前端的实时练唱音高监测工具。它通过浏览器麦克风采集声音，在本地使用 Web Audio API 与 YIN 音高检测算法分析当前音高，并以调音器、钢琴窗轨迹和音域统计的形式反馈演唱状态。

项目不依赖后端服务，不上传录音数据，适合作为声乐练习、音准训练、发声稳定性观察和前端音频处理学习示例。

## 功能概览

- **实时音高检测**：打开麦克风后实时识别当前频率与最接近的十二平均律音名。
- **调音器式音准反馈**：显示当前音高相对标准音的 cents 偏差，并用指针展示偏高或偏低。
- **稳定性评估**：根据最近一段音高偏差的波动程度判断“采样中 / 很稳定 / 较稳定 / 波动明显”。
- **音量监测**：显示实时音量数值，并提供音量条辅助判断输入是否过小。
- **钢琴窗轨迹**：像 Auto-Tune / Melodyne 的音高编辑窗口一样，在时间轴上绘制最近 14 秒的音高曲线。
- **音域切换**：支持男低、男高、女低、女高、宽音域等显示范围。
- **参考音播放**：点击钢琴窗左侧琴键，可播放对应音高的正弦参考音。
- **音域统计**：统计当前监听会话中的最高音、最低音、平均音高和音域跨度。
- **首次使用引导**：第一次打开会显示简短操作说明。
- **日夜间主题**：支持深色与浅色主题切换，并通过 localStorage 记忆选择。
- **PWA 支持**：包含 manifest 与 service worker，可缓存核心静态资源。
- **无障碍优化**：包含 `aria-label`、`aria-live`、跳转主内容链接等基础可访问性设计。
- **响应式布局**：桌面端左侧固定调音器，移动端底部悬浮调音器。

## 技术栈

本项目采用原生 Web 技术实现：

- **HTML5**：页面结构、语义化区域、PWA manifest 引入。
- **CSS3**：响应式布局、主题变量、动效、视觉系统。
- **JavaScript**：音频采集、YIN 音高检测、Canvas 绘制、状态管理。
- **Web Audio API**：麦克风输入、AnalyserNode 采样、参考音播放。
- **Canvas 2D API**：钢琴窗背景网格与音高曲线绘制。
- **Service Worker / Cache API**：静态资源缓存。
- **localStorage**：保存主题和首次引导状态。

项目没有构建步骤，也没有 npm 依赖，浏览器可以直接加载源码。

## 快速开始

### 1. 克隆或进入项目目录

```bash
cd vocal-pitch-monitor
```

### 2. 启动本地 HTTP 服务

由于浏览器麦克风权限通常要求安全上下文，建议使用本地 HTTP 服务访问页面，而不是直接双击打开 HTML 文件。

```bash
python -m http.server 3001
```

### 3. 打开页面

访问：

```text
http://localhost:3001
```

### 4. 开始使用

1. 点击页面中的“开始监听”。
2. 允许浏览器访问麦克风。
3. 对着麦克风唱一个稳定单音或一句旋律。
4. 观察左侧调音器、钢琴窗轨迹和音域统计。
5. 点击“停止”结束当前监听会话。

## 使用建议

- 推荐使用最新版 Chrome 或 Edge。
- 尽量在安静环境下使用，减少背景噪声。
- 初次练习建议先唱 2-4 秒稳定长音，避免过多颤音和滑音。
- 麦克风输入不要过小，音量条应有稳定反应。
- 音准偏差在 **±10 cents** 内通常已经很准；初练可以先追求 **±25 cents** 内。
- 网页端检测会受到麦克风质量、距离、房间反射、环境噪声、发声方式和浏览器音频实现影响，结果适合作为练习参考。

## 页面模块说明

### 1. 首次使用引导

首次打开时，页面会显示引导弹窗，提示用户：

- 点击“开始监听”并授权麦克风；
- 唱一个稳定单音；
- 观察调音器与钢琴窗轨迹。

关闭后会在 localStorage 中写入 `vs_guide_seen`，下次访问不再自动显示。

### 2. 实时调音器

调音器位于桌面端左侧，移动端底部。它展示：

- 当前识别音名，例如 `A4`、`C#5`；
- 当前频率，例如 `440.0 Hz`；
- 最近标准音频率；
- cents 偏差；
- 音高稳定性；
- 输入音量与音量条。

偏差指针以中间为 0 cents，左侧表示偏低，右侧表示偏高，显示范围按 `-50 ~ +50 cents` 进行视觉限制。

### 3. 钢琴窗音高轨迹

钢琴窗使用 Canvas 绘制：

- 横轴表示最近约 14 秒时间；
- 右侧为当前时间，左侧为过去时间；
- 纵轴表示 MIDI 音高；
- 曲线表示检测到的音高变化；
- 背景网格标记音名和八度；
- 曲线断开代表中间有较长时间没有连续音高。

点击左侧琴键区域会播放对应参考音，方便对照练习。

### 4. 音域范围选择

页面提供以下显示范围：

| 选项 | MIDI 范围 | 说明 |
| --- | --- | --- |
| 男低 | 36 - 67 | 偏低男声音域显示 |
| 男高 | 43 - 76 | 默认范围，适合多数男声练习 |
| 女低 | 48 - 81 | 偏低女声音域显示 |
| 女高 | 55 - 88 | 偏高女声音域显示 |
| 宽 | 33 - 93 | 更宽范围，适合跨音域观察 |

这些范围只影响钢琴窗的显示视野，不改变底层音高检测范围。

### 5. 音域统计

当前监听会话中，项目会统计：

- **最高音**：检测到的最高 MIDI 音；
- **最低音**：检测到的最低 MIDI 音；
- **平均音高**：所有有效检测频率的平均值；
- **音域跨度**：最高音与最低音之间的半音数，并估算八度数。

点击“停止”后，统计数据会重置。

### 6. 练习建议

页面底部提供简短练习提示，包括观察轨迹是否贴近目标横线、先练稳定长音、理解 cents 范围等。

## 音高检测原理

项目核心检测逻辑在 `app.js` 中，主要流程如下：

1. 使用 `navigator.mediaDevices.getUserMedia()` 请求麦克风输入。
2. 创建 `AudioContext` 与 `AnalyserNode`。
3. 设置 `analyser.fftSize = 4096`，从时域缓冲区读取采样数据。
4. 计算 RMS 音量，过滤过小声音。
5. 对过大峰值进行归一化，降低近距离大信号造成的识别偏移。
6. 使用 YIN 算法估算基频。
7. 过滤不合理频率范围，只接受约 `40 Hz - 2000 Hz` 的结果。
8. 使用指数平滑降低音高抖动。
9. 将频率转换为 MIDI 音高、音名、标准频率和 cents 偏差。
10. 更新调音器、统计数据和钢琴窗轨迹。

### YIN 算法简述

YIN 是一种常见的单音基频检测算法。当前实现大致包括：

- 计算不同延迟 `tau` 下的差分函数；
- 做 cumulative mean normalized difference；
- 寻找低于阈值的局部最小点；
- 通过抛物线插值细化周期估计；
- 使用 `sampleRate / tau` 得到基频。

当前阈值为 `0.15`，适合在较低延迟下获得相对灵敏的检测结果。

## 关键参数

`app.js` 中包含一些影响检测体验的参数：

| 参数 | 当前值 | 作用 |
| --- | --- | --- |
| `SMOOTH` | `0.10` | 频率平滑系数，越小越稳但响应越慢 |
| `CENTS_SMOOTH` | `0.12` | cents 偏差平滑系数 |
| `VOLUME_THR` | `0.002` | 有效声音的 RMS 音量阈值 |
| `HOLD_MS` | `800` | 短暂无音高时保持上一音高轨迹的时间 |
| `JUMP_CENTS` | `600` | 过滤突变音高的阈值 |
| `ROLL_WINDOW` | `14000` | 钢琴窗显示的时间窗口，单位毫秒 |
| `fftSize` | `4096` | AnalyserNode 时域采样缓冲大小 |

这些参数可以根据实际麦克风、声源距离、响应速度偏好进行微调。

## 数据与隐私

- 音频采集与音高分析完全在浏览器本地进行。
- 项目没有后端接口，不会主动上传录音或检测结果。
- localStorage 只保存：
  - `vs_guide_seen`：是否已经看过引导；
  - `vs_theme`：当前主题选择。
- 如果通过第三方静态托管部署，仍需确认托管平台自身的访问日志与隐私政策。

## PWA 与离线缓存

项目包含：

- `manifest.json`：定义应用名称、主题色、启动路径和图标；
- `service-worker.js`：安装时缓存核心资源，并在请求时优先返回缓存。

当前缓存名为：

```js
vocal-studio-v2
```

缓存资源包括：

```js
["./", "./index.html", "./style.css", "./app.js", "./manifest.json"]
```

更新静态资源后，如果浏览器仍显示旧内容，可以尝试：

- 强制刷新页面；
- 在开发者工具中清除站点数据；
- 修改 `service-worker.js` 中的缓存版本名。

## 常见问题

### 浏览器提示无法使用麦克风

请检查：

- 是否通过 `localhost` 或 HTTPS 访问；
- 浏览器地址栏是否允许麦克风权限；
- 系统隐私设置是否允许浏览器使用麦克风；
- 是否有可用麦克风设备。

### 页面一直显示“音量太小”

可能原因：

- 距离麦克风太远；
- 系统输入音量太低；
- 浏览器没有选中正确的输入设备；
- 环境噪声或人声不够清晰。

可以尝试靠近麦克风、提高系统输入音量，或换用外接麦克风。

### 音高曲线跳动明显

可能原因：

- 唱的是滑音、颤音或含气声较多；
- 背景噪声较大；
- 输入过载或爆音；
- 多个声源同时进入麦克风；
- 网页端算法对复杂音色的鲁棒性有限。

建议先唱稳定长音，确认输入音量正常，再进行旋律练习。

### 修改代码后页面没有更新

如果启用了 service worker，浏览器可能返回缓存资源。可以尝试：

1. 打开浏览器开发者工具；
2. 进入 Application / 应用 面板；
3. 清除 Service Worker 和 Cache Storage；
4. 重新刷新页面。
