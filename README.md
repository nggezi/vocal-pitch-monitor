# Vocal Studio - 实时练唱音高监测

Vocal Studio 是一个纯前端的实时练唱音高监测工具。它通过浏览器麦克风采集声音，在本地使用 Web Audio API 与 YIN 音高检测算法分析当前音高，并以调音器、钢琴窗轨迹和音域统计的形式反馈演唱状态。

项目不依赖后端服务，不上传录音数据，适合作为声乐练习、音准训练、发声稳定性观察和前端音频处理学习示例。

> 当前版本：**v4.1**

## 功能概览

- **实时音高检测**：打开麦克风后实时识别当前频率与最接近的十二平均律音名。
- **调音器式音准反馈**：显示当前音高相对标准音的 cents 偏差，并用指针展示偏高或偏低。
- **稳定性评估**：根据最近一段音高偏差的波动程度判断"采样中 / 很稳定 / 较稳定 / 波动明显"。
- **音量监测**：显示实时音量数值，并提供音量条辅助判断输入是否过小。
- **钢琴窗轨迹**：像 Auto-Tune / Melodyne 的音高编辑窗口一样，在时间轴上绘制最近 14 秒的音高曲线。
- **音域切换**：支持男低、男高、女低、女高、宽音域等显示范围。
- **参考音播放**：点击钢琴窗左侧琴键，可播放对应音高的正弦参考音。
- **跟唱模式**：输入目标音高序列，钢琴窗显示目标阶梯线，逐音实时评分。
- **练习模板**：一键生成大调/小调/五声音阶、琶音、三度跳进、八度跳进，可选根音。
- **旋律试听**：跟唱前先按目标音高和节奏播放一遍。
- **偏差着色**：轨迹按音准偏差染色（±10¢ 绿 / ±25¢ 橙 / 超出红）。
- **音域统计**：统计当前监听会话中的最高音、最低音、平均音高和音域跨度。
- **音准保持**：实时显示 ±10 cents 内的音准保持率。
- **颤音分析**：检测最近 3 秒轨迹的颤音频率与幅度。
- **录音回放**：监听时自动录音，可回放并与当时音高轨迹同步观看。
- **轨迹导出**：一键导出当前轨迹为 CSV / JSON。
- **练习历史**：自动保存最近 20 次练习的时长、音域与音准，记录进步。
- **音准趋势图**：练习历史中显示音准保持率的变化折线。
- **麦克风选择**：可切换输入设备，选择会记忆到 localStorage。
- **键盘快捷键**：支持空格、1-5 数字键、T、C、?、Esc 等快捷键，快速操控所有功能。
- **首次使用引导**：第一次打开会显示简短操作说明，按 `?` 键可随时重新打开。
- **日夜间主题**：支持深色与浅色主题切换，并通过 localStorage 记忆选择。
- **PWA 支持**：包含 manifest 与 service worker，可缓存核心静态资源，支持离线访问。
- **无障碍优化**：包含 `aria-label`、`aria-live`、`focus-visible`、`prefers-reduced-motion` 等可访问性设计。
- **响应式布局**：桌面端左侧固定调音器，移动端底部悬浮调音器。

## 技术栈

本项目采用原生 Web 技术实现：

- **HTML5**：页面结构、语义化区域、PWA manifest 引入。
- **CSS3**：响应式布局、主题变量、动效、视觉系统。
- **JavaScript**：音频采集、YIN 音高检测、Canvas 绘制、状态管理。
- **Web Audio API**：麦克风输入、AnalyserNode 采样、参考音播放。
- **Canvas 2D API**：钢琴窗背景网格与音高曲线绘制。
- **Service Worker / Cache API**：静态资源缓存、离线回退。
- **localStorage**：保存主题和首次引导状态。

项目没有构建步骤，也没有 npm 依赖，浏览器可以直接加载源码。

## 快速开始

### 1. 克隆或进入项目目录

```bash
cd vocal-pitch-monitor
```

### 2. 启动本地 HTTP 服务

由于浏览器麦克风权限通常要求安全上下文，建议使用本地 HTTP 服务访问页面，而不是直接双击打开 HTML 文件。

```bash
python -m http.server 3001
```

### 3. 打开页面

访问：

```text
http://localhost:3001
```

### 4. 开始使用

1. 点击页面中的"开始监听"（或按 `Space` 键）。
2. 允许浏览器访问麦克风。
3. 对着麦克风唱一个稳定单音或一句旋律。
4. 观察左侧调音器、钢琴窗轨迹和音域统计。
5. 点击"停止"（或再按 `Space`）结束当前监听会话。

## 使用建议

- 推荐使用最新版 Chrome 或 Edge。
- 尽量在安静环境下使用，减少背景噪声。
- 初次练习建议先唱 2-4 秒稳定长音，避免过多颤音和滑音。
- 麦克风输入不要过小，音量条应有稳定反应。
- 音准偏差在 **±10 cents** 内通常已经很准；初练可以先追求 **±25 cents** 内。
- 网页端检测会受到麦克风质量、距离、房间反射、环境噪声、发声方式和浏览器音频实现影响，结果适合作为练习参考。

### 2. 实时调音器

调音器位于桌面端左侧，移动端底部。它展示：

- 当前识别音名，例如 `A4`、`C#5`；
- 当前频率，例如 `440.0 Hz`；
- 最近标准音频率；
- cents 偏差；
- 音高稳定性；
- 输入音量与音量条。

偏差指针以中间为 0 cents，左侧表示偏低，右侧表示偏高，显示范围按 `-50 ~ +50 cents` 进行视觉限制。

钢琴窗使用 Canvas 绘制：

- 纵轴表示 MIDI 音高；
- 曲线表示检测到的音高变化；
- 背景网格标记音名和八度；
- 曲线断开代表中间有较长时间没有连续音高。

点击左侧琴键区域会播放对应参考音，方便对照练习。

### 5. 音域统计

## 音高检测原理

项目核心检测逻辑在 `app.js` 中，主要流程如下：

1. 使用 `navigator.mediaDevices.getUserMedia()` 请求麦克风输入。
2. 创建 `AudioContext` 与 `AnalyserNode`，并自动处理 Chrome 的 `resume()` 要求。
3. 设置 `analyser.fftSize = 4096`，从时域缓冲区读取采样数据。
4. 经 60 Hz 高通滤波后，计算 RMS 音量，过滤过小声音。
5. YIN 的 CMND 自带幅度归一化，适配不同音量输入。
6. 使用 YIN 算法估算基频。
7. 过滤不合理频率范围，只接受约 `55 Hz - 1500 Hz` 的人声结果。
8. 使用自适应指数平滑降低抖动：偏差小时重平滑，转音时快攻收敛。
9. 将频率转换为 MIDI 音高、音名、标准频率和 cents 偏差。
10. 更新调音器、统计数据和钢琴窗轨迹。

### YIN 算法简述

YIN 是一种常见的单音基频检测算法。当前实现大致包括：

- 计算不同延迟 `tau` 下的差分函数；
- 做 cumulative mean normalized difference；
- 寻找低于阈值的局部最小点；
- 通过抛物线插值细化周期估计；
- 使用 `sampleRate / tau` 得到基频。

当前阈值为 `0.15`，适合在较低延迟下获得相对灵敏的检测结果。

### v3.0 算法优化

- 使用插入排序（insertion sort）替代 `Array.sort()` 进行中值滤波，对小数组性能更优。
- 添加 `isListening` 状态判断，避免重复启动。
- 添加 `beforeunload` 事件处理，页面卸载时自动释放音频资源。

### v3.1 检测优化

- 修复转音卡顿：跳变帧不再被硬丢弃，改为「快攻收敛 + 八度跳变两帧确认」，连续旋律不再冻结在旧音高。
- 去掉多余的 cents 二次平滑，转音时自动切换到快攻系数，检测延迟明显下降。
- YIN 限定人声频率搜索范围（55–1500 Hz）、复用缓冲区，并增加周期置信度门控，降低 CPU 占用与噪声误判。
- 钢琴窗重绘降至 30fps，缓存主题颜色、去重重复 DOM 写入。

### v3.2 泛音纠偏

- 修复弱基频音色（高音区、某些元音）把泛音当基频导致的音高抽动。
- YIN 优先寻找第一个足够深的周期谷（CMND < 0.05），跳过半周期/三分之一周期处的浅泛音谷。
- 八度/泛音级跳变需连续 3 帧确认才采信；确认期间保持当前音高并保持轨迹连续，不再丢帧。

### v3.3 输入优化与工程化

- 麦克风输入增加 60 Hz 高通滤波，滤除电源哼声与低频隆隆声，减少噪声误判。
- 支持 A4 标准音校准（440/441/442/443 Hz），选择会记忆到 localStorage。
- 检测循环限频至 30fps，CPU 占用减半；新增削波提示，输入过大时提醒远离麦克风。
- 从后台切回页面时自动恢复 AudioContext，避免"切回来卡住不更新"。
- YIN 检测核心抽为独立模块 `pitch.js`，并新增回归测试（`node test/pitch.test.js`）。
- 宽音域显示上限与检测上限对齐（MIDI 90 / 1500 Hz），消除永远画不出轨迹的空区域。

### v3.4 时间轴对齐修复

- 修复钢琴窗时间网格竖线与轨迹相对位置随时间漂移的问题：竖线改为与轨迹使用同一时间基准动态绘制。
- 新增当前时刻播放指针竖线，与 "now" 标签对齐，直观标示实时位置。

| 参数 | 当前值 | 作用 |

| `VOLUME_THR` | `0.0015` | 有效声音的 RMS 音量阈值 |

| `OCTAVE_CENTS` | `900` | 疑似八度/泛音跳变的阈值 |
| `OCTAVE_CONFIRM_FRAMES` | `3` | 八度/泛音跳变需连续确认的帧数 |

| `HISTORY_MAX` | `20` | 练习历史最大保存条数 |
| `VIBRATO_WINDOW_MS` | `3000` | 颤音分析时间窗口 |

## 常见问题

### 浏览器提示无法使用麦克风

请检查：

- 是否通过 `localhost` 或 HTTPS 访问；
- 浏览器地址栏是否允许麦克风权限；
- 系统隐私设置是否允许浏览器使用麦克风；
- 是否有可用麦克风设备。

### 页面一直显示"音量太小"

可能原因：

- 距离麦克风太远；
- 系统输入音量太低；
- 浏览器没有选中正确的输入设备；
- 环境噪声或人声不够清晰。

可以尝试靠近麦克风、提高系统输入音量，或换用外接麦克风。

### 音高曲线跳动明显

可能原因：

- 唱的是滑音、颤音或含气声较多；
- 背景噪声较大；
- 输入过载或爆音；
- 多个声源同时进入麦克风；
- 网页端算法对复杂音色的鲁棒性有限。

建议先唱稳定长音，确认输入音量正常，再进行旋律练习。

### 修改代码后页面没有更新

如果启用了 service worker，浏览器可能返回缓存资源。可以尝试：

1. 打开浏览器开发者工具；
2. 进入 Application / 应用 面板；
3. 清除 Service Worker 和 Cache Storage；
4. 重新刷新页面。

## v3.1 更新日志

### Bug 修复
- 修复转音时调音器冻结在旧音高的问题（此前超过 150 cents 的跳变帧会被直接丢弃，且永不更新平滑值）
- 修复 YIN 在周期整数倍处因数值下溢导致的八度误检

### 稳定性

- 疑似八度错音需连续两帧确认才会采信
- AudioContext 使用 `latencyHint: "interactive"` 降低音频链路延迟
